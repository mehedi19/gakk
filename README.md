# Gakk Media — Next.js 14 Web Application

Premier digital systems engineering, high-throughput telecom VAS, and digital product experience platform.

## Features
- **Three.js 3D Particle Logo Engine**: 2,100 stippled points with cursor repulsion blow-out and scroll scatter physics.
- **Liquid-Glass Cursor Follower**: 120 FPS hardware-accelerated lerp tracking with dynamic action tags.
- **Authentic Gakk Geometry**: Solid black corporate emblem with bold geometric typography.
- **6 Proprietary Sub-Brands**: Shadhin, Deen, WIN, Cloud7, PocketPlay, OneAI.
- **Interactive Product Details Route**: Complete architecture deep dives and live telecom node monitoring.
- **Cuberto Showreel Section**: Native video player with fullscreen modal and audio controls.
- **Live Project Cost Estimator**: Milestone-based budget calculator with Gemini AI architectural blueprint scoping.
- **Design System Rules**: Sharp 0px corners (`rounded-none`) on all cards/sections; 100% corners (`rounded-full`) on all CTAs.

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open browser at http://localhost:3000
```

## Deployment
Push directly to GitHub and deploy with zero configuration on [Vercel](https://vercel.com).
